## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend & Framework**: Next.js 14 App Router, React 18, TypeScript
- **Styling & UI**: Tailwind CSS, Next-Themes (Light/Dark Mode), Lucide Icons
- **Typography**: خط Cairo العربي من Google Fonts
- **Database**: Supabase PostgreSQL (Cloud) & Prisma ORM (SQLite for local dev)
- **Live Video**: Jitsi Meet SDK
- **Internationalization**: next-intl (العربية RTL والإنجليزية LTR)
